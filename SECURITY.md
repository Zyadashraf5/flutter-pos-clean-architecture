# Security and scope

This is a portfolio code sample. The README documents tested behavior and known limitations. Do not assume a successful build makes it ready for production.

Do not commit signing keys, service-account files, access tokens, passwords or real customer data. Firebase client identifiers are not authorization; protect resources with reviewed server-side permissions and Firebase Security Rules.

Use fictional data and demo Firebase projects for local review. Never deploy emulator-only rules to a real project. No production Firebase services were changed while preparing this code sample.

Report a suspected vulnerability privately to zyadashraf48@gmail.com. Do not include working secrets or customer data in a public issue.
